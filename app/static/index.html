PapilAlert checks retinal fundus image quality and runs an experimental model for optic-disc edema (ODE). It is built for transparent research review—not diagnosis.

CURRENT MODEL MobileNetV3-Small Binary image classifier TARGET Optic-disc edema Not papilledema diagnosis
!
Research use only — not a medical device

Do not use this output to diagnose, rule out, or triage a patient. ODE has multiple causes. The model cannot diagnose papilledema or measure intracranial pressure. A qualified eye-care professional must interpret any image.

    01 / IMAGE CHECKS

    Before inference

    Basic resolution, illumination, clipping and blur-proxy checks help identify some technically unsuitable images. These heuristics are not clinically validated quality standards.

    02 / CLASSIFIER

    Two output classes

    MobileNetV3-Small estimates scores for no_ode and optic_disc_edema. It does not predict the cause of swelling or diagnose papilledema.

    03 / HUMAN REVIEW

    Keep a clinician in the loop

    Research scores and Grad-CAM overlays require specialist interpretation. The interface abstains when configured score or margin checks indicate uncertainty.
