# Data directory

Place only data that you are legally permitted to use here.

Expected example:

```text
images/
  normal/
  pseudopapilledema/
  optic_neuropathy_mixed/
```

Important: the last label must mean exactly what the source dataset says. The Ahn et al. (2019) 295-image optic-neuropathy group is mixed and includes only 22 papilledema cases. Do not rename it to `papilledema`.

Read `../docs/DATASET_AUDIT.md` before considering any public mirror of that dataset. Do not distribute patient images in the submission ZIP unless the license explicitly allows it.
